# Plataforma de Triagem e Atendimento Social Interdisciplinar

Projeto Integrador desenvolvido para centralizar a triagem e o
direcionamento de atendimentos gratuitos oferecidos à comunidade.

## MVP

Nesta primeira etapa foi implementada uma tela de triagem utilizando
Kotlin e Jetpack Compose.

A tela permite:

- informar nome;
- informar idade;
- selecionar uma área de atendimento;
- realizar uma triagem simples;
- visualizar o resultado na interface.

## Tecnologias

- Jetpack Compose
